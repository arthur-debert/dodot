- fix: a `Brewfile` run no longer upgrades packages you did not ask about. `brew bundle` upgrades every outdated formula it encounters by default, so what reads as "install what this Brewfile declares" could become a long mutating upgrade of unrelated software. dodot now passes `--no-upgrade`; upgrading stays something you ask for, with `brew upgrade` (#358).
- fix: a `Brewfile` run no longer pays for brew's auto-update. The first brew invocation of a day normally runs a `brew update` first — seconds of network traffic upgrading brew and its taps before your packages get a look in. dodot now sets `HOMEBREW_NO_AUTO_UPDATE` for the invocation, so `dodot up` costs what your Brewfile costs (#358).
- change: provisioning handlers can declare environment variables for the command they run. The variables are stated in the handler's compile-time descriptor — no `.dodot.toml` reaches them — and are layered onto the environment dodot itself is running with, so a handler that declares none spawns exactly as before, with your `PATH`, `HOME`, and the rest intact (#358).
