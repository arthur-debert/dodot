- fix: nix runs now record the manifest they ran. `run_and_record` used to take the file it ran from the command's *last* argument, a convention `install` and `homebrew` happen to satisfy and `nix` does not — its command ended in `--extra-experimental-features 'nix-command flakes'`, so a nix run wrote no `.snapshot` beside its sentinel and printed `==== <pack> → nix → nix-command flakes` as its progress header. `dodot status --diff` was therefore permanently unavailable for `packages.nix`. Each provisioning handler now declares where its manifest sits in the command's arguments, in a compile-time descriptor registry that no `.dodot.toml` can reach (#354).
- fix: `nix profile install` now runs with `--impure`, without which no manifest shape dodot documents evaluates at all: `--expr` evaluates in Nix's pure mode, which refuses to read both an absolute `packages.nix` path and the `<nixpkgs>` that `{ pkgs ? import <nixpkgs> {} }:` resolves from `NIX_PATH`. Verified against Nix 2.35.2 (#354).
- change: dodot passes your manifest's path to nix as `--argstr manifest <path>` and the wrapper expression reads it as a Nix function parameter, instead of interpolating the path into the expression's text. The expression is now identical for every pack, and a manifest path containing a quote, a backslash, or a `${` needs no escaping into Nix source (#354).
