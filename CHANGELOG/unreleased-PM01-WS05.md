- feat: a Homebrew too old for your `Brewfile` is now named before the run, not decoded from a parse error afterwards. `go`, `cargo`, `uv`, `npm`, and `krew` entries need Homebrew 5.1.2 or newer, and dodot's own `HOMEBREW_NO_AUTO_UPDATE` stops brew from quietly updating itself past that line — so `dodot up` asks `brew --version` first and reports a below-floor brew with `brew update` as the remedy. It reports rather than refuses: dodot does not read your `Brewfile`, and a file of plain `brew` lines runs fine on an older installation. A brew at or above the floor says nothing (#359).
- change: the version question is asked only by `dodot up`, only for a `Brewfile` that is actually about to run, and once per machine per run however many packs declare one. `dodot status` and `dodot up --dry-run` still spawn nothing at all — they answer "is brew here?" from the filesystem, which is what keeps them free to run (#359).
